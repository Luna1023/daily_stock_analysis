# 水彩配色记录器

为自制固体水彩准备的小工具：从**图片 / 视频 / 链接**中取色，按你手头的颜料推算**配比与每批用量**，并把配方**记录**下来（含预测色、实际成品色、备注）。

这是一个独立的小应用，与仓库里的股票分析系统没有代码耦合；仅使用 Python 标准库和原生浏览器能力，无需安装依赖，也不需要 `.env` 配置。

## 启动

```bash
cd apps/watercolor-recorder
python recorder_server.py            # 默认 http://127.0.0.1:8765
python recorder_server.py --port 9000
```

`--host` 默认只监听本机。若改为 `0.0.0.0` 暴露到局域网，请自行评估：服务会代你访问外部链接（已拦截内网 / 回环地址，但没有登录保护）。

## 使用流程

1. **提供参考**（配色生成 → 步骤 1）
   - 图片：选择文件、拖拽或直接粘贴；点击画面任意位置取色（5×5 像素均值），也可以直接点「画面主色」色块。
   - 视频：选择文件，用进度条 / ±0.1s 按钮停在想要的画面，点「截取当前帧」。
   - 链接：粘贴图片或视频直链，或含图片的网页地址（读取 `og:image`、`<img>`、`<video>`），再选择候选素材。B 站 / YouTube 等视频平台的播放页无法直接读取，请下载后上传或截图。
   - 也可以不上传素材，直接输入 `#RRGGBB`。
2. **生成配比**（步骤 2）：选择最多用几种颜料（2–4）和每批颜料总量，点「生成配比」。每种用料数各给一个最优方案；色差 ΔE00 相差不大时，推荐用料更少的那个。只会使用「原料库」里勾选为「已有」的颜料。
3. **编辑并记录**（步骤 3）：对方案点「编辑并记录」，或「新建手动配方」。份数可填任意正数（如 `3 : 2 : 1`，或直接填克数），自动换算为百分比，并实时给出预测色、每种颜料克数、胶液克数和辅料克数。做好并干燥后，可以把实际成品色取色填入，系统会计算它与目标色的色差。
4. **配方记录**：搜索、编辑、删除，导出 JSON（完整备份，可再导入）或 CSV。

## 原料库

- 内置约 20 种常见颜料，色值是干燥后纯色的**近似屏幕色**，只是起点。
- 想更准：把自己做好的色块拍照或扫描，在「配色生成」里取色，再点该颜料的「取当前目标色」校准。
- **着色力**：越大，少量就能显色（如酞菁类）。**遮盖力**：越高，加入后越不透明（如白、土色）。**胶液 g/g**：每 1g 颜料需要的粘合剂溶液克数。
- 「粘合剂与辅料」中的名称、比例可自行修改。默认值（蜂蜜 8%、甘油 4%、丁香油 / 防腐剂 1%）只是常见起点，请结合手感和干燥效果调整，不构成配方保证。

## 混色模型与局限

配比由简化的 Kubelka–Munk 模型估算：对线性 RGB 的每个通道，把每种颜料的 K/S 按「比例 × 着色力 × 遮盖力」加权混合，白色因遮盖力高会稀释着色颜料。黄 + 蓝得到绿、加白变浅、颜料越多越灰，趋势符合真实水彩。

但它**只是近似**：

- 输入是屏幕 RGB，不是颜料的光谱数据；同色异谱、颗粒沉淀、纸张底色、水量与干后变浅 / 变灰都没有建模。
- 手机拍摄的色彩受光线与白平衡影响，建议在均匀自然光下拍参考物和成品。
- 预测结果请当作起点，用少量试色后再按「实际成品色」迭代。

## 数据存放

配方、原料库、辅料设置保存在浏览器的 `localStorage`（同一浏览器、同一地址与端口下可见）。更换浏览器、清除站点数据或修改端口会看不到旧数据，请定期「导出 JSON」备份。保存的配方会记录当时的颜料色值和参数快照，之后修改原料库不会改变旧配方。

## 链接解析的安全边界

- 仅允许 `http` / `https`；域名解析结果只要含内网、回环、链路本地地址就拒绝，每一跳重定向都会重新校验。
- 网页 2MB、图片 20MB、视频 80MB 上限；支持 gzip / deflate 响应并限制解压后体积。
- 服务只会转发 `image/*` 与 `video/*`。
- 校验与实际连接之间仍有 DNS rebinding 的理论窗口，因此默认只绑定本机；不建议把它暴露到公网。
